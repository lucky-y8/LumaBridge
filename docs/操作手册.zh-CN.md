# LumaBridge 中文操作手册

[English User Manual](USER_MANUAL.en.md)

## 1. 用途与传输方式

LumaBridge 通过以下光学流程在隔离电脑之间传输单个文件：

1. 发送电脑循环播放动态二维码。
2. 手机拍摄电脑屏幕；手机不需要安装配套 App。
3. 通过获准的本地方式把录像放到接收电脑。
4. 接收电脑使用 LumaBridge 扫描一段或多段录像，收集唯一分片并验证结果。

软件不会连接服务器，也不包含账号、遥测、广告或自动更新。

软件默认使用 Codex 风格浅色主题。点击侧栏底部的“切换深色模式”可使用深色界面；切换主题不会改变二维码播放背景或编码数据。

## 2. 使用前准备

- Windows 便携版必须保持 `LumaBridge.exe` 与 `_internal` 目录在一起。
- 确认发送电脑能够完整显示二维码，没有缩放或裁切。
- 确认手机空间足够录制两个播放循环。
- 关闭美颜、滤镜，避免通过聊天软件二次压缩录像。
- 正式传输前，建议先用约 10 KB 的小文件测试完整流程。

## 3. 发送文件

1. 打开左侧的“发送文件”。
2. 将单个文件拖入窗口，或点击“浏览文件”。
3. 等待后台完成 SHA-256 分析。
4. 查看文件大小、分片数量、单循环时长和推荐录像时间。
5. 选择发送模式：
   - **稳定：** 500 字节、2 fps，适合反光、小屏幕或识别能力较弱的摄像头。
   - **标准：** 700 字节、3 fps，默认推荐。
   - **快速：** 800 字节、4 fps，适合清晰屏幕和固定拍摄。
   - **自定义：** 分片 200～1000 字节，速度 0.5～8 fps。
6. 如果需要另一人操作手机，建议保留播放前 3 秒倒计时。
7. 选择播放 2 次或无限循环。
8. 点击“开始全屏播放”。

### 全屏快捷键

| 按键 | 作用 |
| --- | --- |
| `Esc` | 停止播放并返回主程序 |
| 空格 | 暂停或继续 |
| 左/右方向键 | 暂停并切换到上一/下一分片 |

## 4. 手机录像

建议手机横屏、1080p/60fps 录像，并至少录制两个完整循环。

为了提高识别率：

- 使用支架固定手机，让镜头尽量与显示器平行。
- 二维码和四周白色静区必须完整进入画面。
- 点击二维码区域对焦；白色区域过曝时适当降低曝光。
- 避免反光、数码变焦、防抖裁切和移动阴影。
- 出现滚动黑条时，可尝试 30 fps、降低显示器亮度或使用 1/60 快门。
- 识别效果仍然较差时，改用“稳定”模式重新录制。

## 5. 恢复文件

1. 打开左侧的“恢复文件”。
2. 添加 MP4、MOV、AVI、MKV、M4V 或 WebM 录像。
3. 删除无关录像，或用“上移/下移”调整扫描顺序。
4. 初次建议保持每秒识别 12 次；困难录像可提高到 20～30 次。
5. 点击“开始扫描”。
6. 同时观察两类进度：
   - **当前视频扫描进度：** 表示已经读取到录像的哪个位置。
   - **唯一分片收集进度：** 表示原文件已经收集了多少。
7. 可随时暂停、继续或取消；已经收集的分片会保留。

单个损坏或不支持的视频会被标记并跳过。若同一分片编号出现不同内容，软件会停止安全恢复，不能忽略该冲突。

## 6. 分片不完整与补录

如果所有录像扫描完毕后仍未收齐：

1. 查看缺失数量以及从 1 开始的缺失编号。
2. 点击“保存状态”，妥善保存 `.qrstate` 文件。
3. 改善对焦或使用“稳定”模式，再补录一个完整循环。
4. 重新打开软件，点击“加载状态”。
5. 添加补录视频并再次开始扫描。

状态文件包含已经恢复的原始分片，应按照原文件相同的敏感级别保管。它使用 JSON 而不是 Python Pickle，并通过临时文件和原子替换保存。

## 7. 保存恢复文件

所有分片收齐后，点击“恢复并保存文件”。软件会：

1. 按协议编号排序分片。
2. 按声明的文件长度精确重建数据。
3. 验证最终文件大小。
4. 验证完整 SHA-256。
5. 先写临时文件，校验通过后再原子改名。

目标位置已有同名文件时不会静默覆盖。只有软件明确显示文件大小和 SHA-256 验证成功，才应把结果视为与原文件逐字节一致。

## 8. 进度与计数含义

- **已识别二维码：** 从抽样视频帧中读到的 QRF1 二维码次数。
- **新增：** 当前文件新接受的唯一分片。
- **重复：** 与已有内容相同的分片；录制多个循环时属于正常现象。
- **CRC 错误：** 数据与自身 CRC32 不一致，已拒绝。
- **其他文件：** 属于另一会话的有效 QRF1 分片，已忽略。
- **预计剩余时间：** 根据视频读取速度估算，不代表分片何时能够收齐。

## 9. 常见问题

### 完全识别不到二维码

确认录像内容确实是 LumaBridge/QRF1 二维码，白色静区完整、对焦清晰。可提高每秒识别次数，或使用“稳定”模式重新录制。

### 分片进度停在接近完成的位置

只要视频扫描进度仍然变化，软件就没有卡死，而是在继续寻找缺失分片。等待录像扫描结束，保存状态并添加补录录像。

### 视频无法打开

打包版 OpenCV/FFmpeg 可能不支持该视频编码。可转换为常规 H.264 MP4，但不要缩放、旋转或裁掉二维码白边。

### SHA-256 不一致

软件不会报告成功。保留状态文件并扫描更清晰的录像，不要把临时或不完整输出当作原文件使用。

## 10. 日志与隐私

“任务日志”显示用户操作记录，“打开日志目录”可查看滚动技术日志。日志包含错误与计数，但不包含完整二维码载荷或原始文件内容。LumaBridge 正常运行时不会发起网络请求。
